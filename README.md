# AI-Driven Workflow Exploration Project

## 1. Project Overview
This project documents my process of setting up an AI-integrated development environment using Cursor IDE, Claude Code, and Codex. As a Growth Marketer, I am exploring how these tools can optimize technical marketing workflows.

## 2. Tools Installed
- **Cursor IDE:** Primary AI-native editor.
- **Claude Code & Codex:** For advanced reasoning and task automation.
- **Cursor AI Agent:** Used for automated repository management and troubleshooting.
- **Git & GitHub:** For version control and portfolio hosting.

## 3. Workflow & Steps Completed
1. Installed **Cursor IDE** and set it up as my local workspace.
2. Navigated the Cursor Extension Marketplace to find and install the **Claude Code** and **Codex** add-ons.
3. Created a public GitHub repository (using my existing account) and connected it to my local environment via Git cloning.
4. Collaborated with the Cursor AI Agent to navigate terminal commands and local environment setups.
5. Drafted this `README.md` to document the journey, issues, and solutions.
6. Authenticated my Git identity locally and pushed the final project back to GitHub.

## 4. Troubleshooting & Solutions
My setup process involved active problem-solving with the help of AI agents, turning technical hurdles into learning opportunities:

- **Extension Installation Approach**
  - *Issue:* Initially, I tried to install the required extensions by running commands directly in the terminal, which resulted in errors.
  - *Solution:* I used the **Cursor Extension Marketplace** to search for and install the officially verified versions, ensuring a secure and stable setup.
- **Environment Path Hurdles**
  - *Issue:* The AI Agent identified that `git` was not recognized in the terminal PATH after installation.
  - *Solution:* I worked with the Agent to invoke the `git.exe` executable directly from the install folder, allowing me to complete the repository clone without manual PATH debugging.
- **Git Identity Conflict (Fatal Error)**
  - *Issue:* During the final commit, I encountered a `fatal: unable to auto-detect email address` error.
  - *Solution:* I manually configured the local Git identity (`user.name` and `user.email`) via the terminal, ensuring proper attribution for all contributions.
