# AI-Driven Workflow Exploration Project

### 1. Project Overview
This project documents my process of setting up a modern, AI-integrated development environment using Cursor IDE, Claude Code, and Codex. As a Growth Marketer with a background in high-conversion email campaigns, I am exploring how these tools can optimize technical marketing workflows.

### 2. Tools Stack
- **Cursor IDE**: Primary AI-native editor.
- **Claude Code (Anthropic)**: For advanced reasoning and task automation.
- **AI Agent (Cursor)**: Used for automated repository management and troubleshooting.
- **Git & GitHub**: For version control and portfolio hosting.

### 3. Execution Journey & Troubleshooting (The "Real" Work)
My setup process involved active problem-solving with the help of AI agents, turning technical hurdles into learning opportunities:

- **Issue 1: Command Recognition**: Initially tried running `install` commands directly in PowerShell. Quickly pivoted to the Cursor Extension Marketplace to verify and install official add-ons.
- **Issue 2: Environment Path Hurdles**: The AI Agent identified that `git` was not recognized in the terminal PATH. I installed Git for Windows and worked with the Agent to invoke the executable directly to complete the clone.
- **Issue 3: Git Identity Conflict (Fatal Error)**: During the final commit, I encountered `fatal: unable to auto-detect email address`. 
  - *Solution*: I manually configured the local Git identity (`user.name` and `user.email`) via the Cursor terminal. This ensured all contributions were properly attributed and enabled a successful push to the remote repository.

### 4. Key Results
- Successfully established a local-to-remote pipeline with authenticated commits.
- Mastered the interaction between manual execution and AI Agent assistance.
- Documented a clear "Issue-Action-Result" framework, reflecting my data-driven mindset from previous roles at FMG and Bigcoin Vietnam.

### 5. Reflection
This task proved that the hardest part of adopting new tech is proving the capability to troubleshoot and adapt. My ability to maintain a record-breaking 61.4% Open Rate in email marketing stems from the same persistence and attention to detail shown in this technical setup.
