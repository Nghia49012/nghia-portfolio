# AI-Driven Workflow Exploration Project

### 1. Project Overview
This project documents my process of setting up an AI-integrated development environment using Cursor IDE, Claude Code, and Codex. As a Growth Marketer, I am exploring how these tools can optimize technical marketing workflows.

### 2. What I installed
1. **Cursor IDE**: Primary AI-native editor.
2. **Claude Code and Codex**: For advanced reasoning and task automation.
3. **AI Agent in Cursor**: Used for automated repository management and troubleshooting.
4. **Git & GitHub**: For version control and portfolio hosting.

### 3. What steps I completed
Step 1: Installed **Cursor IDE** and set it up as my local workspace. <br>
Step 2: Navigated the Cursor Extension Marketplace to find and install the **Claude Code** and **Codex** add-ons. <br>
Step 3: I've already had my Github account, so I only need to create a public GitHub repository and connected it to my local environment via Git cloning.<br>
Step 4: Collaborated with the Cursor AI Agent to navigate terminal commands and local environment setups.<br>
Step 5: Drafted this `README.md` to document the journey, issues, and solutions.<br>
Step 6: Authenticated my Git identity locally and pushed the final project back to GitHub.

### 4. Issues I ran into and my solutions
My setup process involved active problem-solving with the help of AI agents, turning technical hurdles into learning opportunities:
1. **Issue 1: Extension Installation Approach**: Initially, I tried to install the required extensions by running commands directly in the terminal, which resulted in errors.
=> *Solution*: I used the **Cursor Extension Marketplace** to search for and install the officially verified versions, ensuring a secure and stable setup.
2. **Issue 2: Environment Path Hurdles**: The AI Agent identified that `git` was not recognized in the terminal PATH after installation.
=> *Solution*: I worked with the Agent to invoke the `git.exe` executable directly from the install folder, allowing me to complete the repository clone without manual PATH debugging.
3. **Issue 3: Git Identity Conflict (Fatal Error)**: During the final commit, I encountered a `fatal: unable to auto-detect email address` error.
=> *Solution*: I manually configured the local Git identity (`user.name` and `user.email`) via the terminal, ensuring proper attribution for all contributions.

### 5. How I Navigated the Learning Curve
- **Video Tutorials**: I watched "Cursor 2.0 - Full Tutorial for Beginners" to quickly grasp the IDE's interface, core features, and best practices.
- **AI Consultation**: I continuously interacted with the built-in AI Agent and Gemini to navigate terminal commands and troubleshoot local environment setup errors in real-time.
