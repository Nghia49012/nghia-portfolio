### 3. Execution Journey & Troubleshooting (The "Real" Work)
My setup process wasn't just "click and install"; it involved active problem-solving with the help of AI agents:

- **Issue 1: Command Recognition**: Initially, I attempted to install extensions via PowerShell commands, which resulted in a `CommandNotFoundException`. 
  - *Solution*: I pivoted to the Cursor Extension Marketplace to manually verify and install official add-ons like Claude Code by Anthropic.
- **Issue 2: Environment Path Hurdles**: When attempting to clone this repository, the AI Agent identified that `git` was not recognized in the terminal PATH.
  - *Solution*: I followed the Agent's guidance to install Git for Windows. [cite_start]Even when the terminal session didn't immediately recognize the new path, I worked with the Agent to invoke `git.exe` directly from the install folder to successfully complete the clone.
